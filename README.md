# claude-experiments

Small experiments built with Claude.

## JS-Codes

- [purpose-of-life](JS-Codes/purpose-of-life/): a 48-second cut-paper animation with synthesized audio · [watch it live](https://akashgoyal.github.io/claude-experiments/JS-Codes/purpose-of-life/)
- [hindi-varnmala](JS-Codes/hindi-varnmala/): a 90-second cut-paper film teaching all 13 swar and 37 vyanjan, with spoken letters · [watch it live](https://akashgoyal.github.io/claude-experiments/JS-Codes/hindi-varnmala/)
- [rashmirathi](JS-Codes/rashmirathi/): an 89-second cut-paper film in new rhymed Hindi verse, inspired by Dinkar's Rashmirathi · [watch it live](https://akashgoyal.github.io/claude-experiments/JS-Codes/rashmirathi/)
- [rashmirathi-saga](JS-Codes/rashmirathi-saga/): a 5-minute cut-paper film of Karna's whole story in seven cantos, in new rhymed Hindi verse inspired by Dinkar's Rashmirathi · [watch it live](https://akashgoyal.github.io/claude-experiments/JS-Codes/rashmirathi-saga/)
