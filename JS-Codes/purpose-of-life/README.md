# Purpose, Piece by Piece

A 48-second hand-drawn, cut-paper collage animation asking *what is the purpose of life?*

**Watch it live:** https://akashgoyal.github.io/claude-experiments/JS-Codes/purpose-of-life/

- Pure JavaScript on a `<canvas>`: no libraries, images, or audio files
- Music and sound effects are synthesized live with the Web Audio API
- Controls: play/pause (or Space), restart, mute, and a clickable progress bar

Open `index.html` in a browser and press **Play with sound**.
