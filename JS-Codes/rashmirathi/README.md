# Krishna's Warning (कृष्ण की चेतावनी)

An 89-second hand-drawn, cut-paper collage film in rhymed Hindi verse, inspired by the
*Krishna ki Chetavani* episode of Ramdhari Singh 'Dinkar''s *Rashmirathi* (1952).

**Watch it live:** https://akashgoyal.github.io/claude-experiments/JS-Codes/rashmirathi/

It covers the end of the Pandavas' exile, Krishna's peace mission to Hastinapur, the request for
five villages, Duryodhana's refusal, Krishna's cosmic form (विराट रूप), his warning of war, and his
meeting with Karna.

- Pure JavaScript on a `<canvas>`: no libraries, images, or audio files
- The rhymed verse was written for this film and is **not** Dinkar's text. *Rashmirathi* is still
  under copyright; the film quotes one line from canto 3, credited on screen. Read the full poem.
- Each half-line is recited on a timed grid by the browser's Hindi text-to-speech voice, if the device has one
- Music is synthesized live with the Web Audio API: tanpura, bansuri, sitar, shankh, nagada, bells
- Controls: play/pause (or Space), restart, mute music, voice on/off, and a clickable progress bar

Open `index.html` in a browser and press **Play with sound**. Chrome and Edge usually include a Hindi voice.
